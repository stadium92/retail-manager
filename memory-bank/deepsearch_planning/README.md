# DeepSearch Planning

This directory contains resources for leveraging OpenAI's DeepSearch model to audit and improve the `retail-manager` project.

## Files

- **[00_SPECIFICATION.md](00_SPECIFICATION.md)**: A refined technical specification summarizing the user's "brain dump", hardware constraints, and strategic goals.
- **[01_DEEPSEARCH_PROMPT.md](01_DEEPSEARCH_PROMPT.md)**: The **ready-to-paste prompt**. Use this file's content to initiate the conversation with the DeepSearch model.

## Usage

1. Open `01_DEEPSEARCH_PROMPT.md`.
2. Copy the entire content.
3. Paste it into the DeepSearch chat interface.
4. Save the DeepSearch model's response back into this directory (e.g., as `02_DEEPSEARCH_REPORT.md`).
