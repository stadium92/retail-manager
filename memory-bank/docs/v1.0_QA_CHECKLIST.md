# ✅ v1.0 Quality Assurance (QA) Checklist

This checklist must be completed on target hardware (Intel Dual Core, 2.5GB RAM) before shipping v1.0.

## 🔑 1. Authentication & Security
- [ ] Verify signup with weak password fails (less than 8 chars, no numbers, no symbols).
- [ ] Verify signup with strong password succeeds.
- [ ] Verify login/logout works offline via LocalBridge.
- [ ] Check Audit Log: Successful login creates a 'user_login' record.
- [ ] Check Audit Log: Failed login creates a 'user_login_failed' record.

## 🛒 2. POS & Sales (Critical Path)
- [ ] Perform a retail sale: Scan -> F4 -> Confirm. Verify stock decreases.
- [ ] Perform a wholesale sale: Check wholesale prices are applied.
- [ ] Print/Generate Proforma: Verify document generation.
- [ ] Delete a sale (Master only): Verify confirmation dialog appears.
- [ ] Check Audit Log: Sale deletion is recorded.

## 📦 3. Inventory & Purchasing
- [ ] Create a new product: Verify it appears in search immediately.
- [ ] Edit product price: Verify Audit Log records the price change (old vs new).
- [ ] Perform a "Régularisation": Adjust stock manually and verify movement record.
- [ ] Reception from Order: Verify quantities match or discrepancies are highlighted.
- [ ] Reception direct (Ad-Hoc): Create direct purchase and verify stock increase.

## 🔄 4. Hybrid Synchronization
- [ ] Record 5 sales while offline. Verify they appear in "Pending Mutations".
- [ ] Connect to internet. Click "Push Mutations".
- [ ] Verify the 5 sales appear on the Master Cloud Dashboard.
- [ ] Verify "LocalBridge Status" indicator turns green/online.

## 🌍 5. Internationalization (i18n)
- [ ] Switch to Bamanankan (bm): Verify POS grid headers and totals are translated.
- [ ] Switch to French (fr): Verify menu and status bar.
- [ ] Verify language choice persists after app restart.

## ⚡ 6. Performance (Dual Core / 2.5GB RAM)
- [ ] App startup time is under 5 seconds.
- [ ] Catalog search (Cmd+K) returns results in under 500ms.
- [ ] Virtualized Stock Listing: Scroll through 1000+ items without lag.
- [ ] Memory Usage: App stays stable under 500MB RAM during heavy POS usage.

## 📖 7. Documentation & UX
- [ ] Open Help section: Verify all articles are readable.
- [ ] Test Tooltips: Hover over "Moyenne Pondérée" or "Déficit".
- [ ] Confirmations: Try to delete a worker; verify safety dialog blocks accidental clicks.

## 🧠 8. System Intelligence & Support
- [ ] Trigger an intentional frontend error: Verify it appears in System Logs with "ERROR" severity.
- [ ] Check System Logs: Verify user navigation (module changes) is tracked.
- [ ] Export Logs: Generate a support bundle (JSON/CSV) and verify it contains the last 100 events.
- [ ] Help Center: Load a Markdown-based FAQ article offline.
- [ ] Bug Report: Submit a report from the Help Center and verify it's saved to the audit table.
