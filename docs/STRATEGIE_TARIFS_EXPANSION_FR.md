## Comment Augmenter les Prix Sans Perdre la Confiance

**Règle** : Ne JAMAIS augmenter les prix pour les clients existants. Uniquement pour les nouveaux.

| Quand | Action |
|-------|--------|
| Après 50 ventes | Annoncez sur votre Statut WhatsApp : *"Nos 50 places de partenaire fondateur sont complètes ! Nouvelle offre : 75 000 FCFA"* |
| Après 150 ventes | Passez à l'abonnement annuel : *"Retail Manager V1.0 est maintenant en ligne ! 100 000 FCFA/an"* |
| Après 500 ventes | Introduisez les niveaux : Standard (100k) vs Premium (200k) |

**La psychologie** : Chaque augmentation de prix confirme la bonne décision des premiers acheteurs. Ils se sentent malins d'avoir acheté tôt. Ils disent à leurs amis : *"Moi je l'ai eu à 50k, maintenant c'est 100k !"* — c'est de la publicité gratuite.
